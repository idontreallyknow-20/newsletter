# Static files

Drop the portrait here as `joseph.jpg` (JPEG, any size; a square or 4:5 crop with the face centred works best).

The site picks it up automatically on the next deploy:

- the round byline photo in the front-page hero
- the large portrait on `/about`
- the small author photo on every issue page

Nothing else needs to change. If the file is missing, a "J" monogram is shown instead.
